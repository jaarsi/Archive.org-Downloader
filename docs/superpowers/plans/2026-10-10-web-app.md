# Archive.org Downloader Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local Next.js web UI to download an archive.org book as PDF (or a ZIP of JPGs), reusing the existing `archive-org-downloader.py` logic via a per-job Python worker with live progress.

**Architecture:** One Next.js server (App Router, TypeScript). A browser form POSTs to an SSE route that spawns `web/worker.py`; the worker loads the existing script by path, reuses its functions (login, loan, image fetch + AES-CTR deobfuscation, img2pdf), and emits one JSON progress line per step on stdout. The route relays those as Server-Sent Events over a `fetch` stream; the finished file is written to a per-job temp folder and downloaded via a second route that deletes the folder afterward.

**Tech Stack:** Next.js 15 / React 19 / TypeScript, Node built-ins (`child_process`, `fs`, `crypto`, `stream`) for the backend glue, `node:test` + `tsx` for unit tests. Python 3 with the existing `requests`, `img2pdf`, `pycryptodome` for the worker (stdlib `zipfile`, `importlib`, `concurrent.futures`).

**Spec:** `docs/superpowers/specs/2026-10-10-web-app-design.md`

## Global Constraints

- The existing `archive-org-downloader.py` at the repo root MUST stay unchanged — the worker loads it by path and reuses its functions.
- All web app code lives under `web/`. The Next.js runtime for API routes is Node (`export const runtime = "nodejs"`), never Edge.
- archive.org credentials are passed to the worker via environment variables (`ARCHIVE_EMAIL`, `ARCHIVE_PASSWORD`) only — never as command-line arguments, never written to disk, never logged.
- The worker writes ONLY JSON (one object per line) to stdout; the reused script's own `print()` chatter is redirected to stderr.
- Temp output lives under `os.tmpdir()/archive-dl/<jobId>`, where `<jobId>` is a 32-char lowercase hex string; the file route validates that shape before touching the filesystem (path-traversal guard).
- Python interpreter is `process.env.PYTHON_BIN || "python3"` (the repo `.venv` has the required modules; `PYTHON_BIN` should point at it when running).
- Pinned versions: `next@15.1.6`, `react@19.0.0`, `react-dom@19.0.0`, `typescript@5.7.3`, `tsx@4.19.2`.

## Review Focus

- **Book URL with a query string or trailing slash** (`.../details/XXXX?foo` or `.../details/XXXX/`) — the worker must extract the bare `book_id`; covered by Task 4's `--selftest`.
- **Credentials containing spaces / shell metacharacters** — must round-trip through env vars, and the password must never appear in the spawn argv; covered by Task 5's `buildWorkerArgs` test.
- **Path traversal on `/api/file/<id>`** (`id = "../../etc"`) — rejected by job-id validation; covered by Task 3's test.
- **Book unavailable / print-disabled-only** (zero page links, or script calls `exit()` on bad login) — must surface as a single `error` event, not a hang or crash; covered by Task 4's missing-creds `--selftest` path and worker's `SystemExit` handling.
- **Client closes the tab mid-download** — the route must kill the worker on request abort so no orphan download keeps running; implemented in Task 5 (verified manually — needs a live run).

```ts
// web/lib/sse.ts
export function createLineBuffer() {
  let buf = "";
  return {
    push(chunk: string): string[] {
      buf += chunk;
      const parts = buf.split("\n");
      buf = parts.pop() ?? "";
      return parts.filter((l) => l.trim() !== "");
    },
    flush(): string[] {
      const rest = buf.trim();
      buf = "";
      return rest ? [rest] : [];
    },
  };
}
```

```ts
// web/lib/jobs.ts
import { randomBytes } from "node:crypto";
import os from "node:os";
import path from "node:path";
import { rm } from "node:fs/promises";

const ROOT = path.join(os.tmpdir(), "archive-dl");
const ID_RE = /^[0-9a-f]{32}$/;

export function newJobId(): string {
  return randomBytes(16).toString("hex");
}

export function jobDir(id: string): string {
  if (!ID_RE.test(id)) throw new Error("invalid job id");
  return path.join(ROOT, id);
}

export async function cleanup(id: string): Promise<void> {
  await rm(jobDir(id), { recursive: true, force: true });
}
```

**Files:**

**Interfaces:**

- Also supports `python3 worker.py --selftest` (asserts `parse_book_id` + missing-creds behavior, exits 0 on success).
- Consumes: the repo-root `archive-org-downloader.py` functions `login`, `loan`, `get_book_infos`, `download_one_image`, `image_name`, `return_loan`.

```python
# web/worker.py
import sys, os, json, argparse, contextlib, importlib.util, zipfile
from concurrent import futures

REAL_OUT = sys.stdout
HERE = os.path.dirname(os.path.abspath(__file__))
SCRIPT = os.path.join(os.path.dirname(HERE), "archive-org-downloader.py")


def emit(**kw):
    REAL_OUT.write(json.dumps(kw) + "\n")
    REAL_OUT.flush()


def parse_book_id(url):
    # strip query/fragment, then take the segment after /details/
    path = url.split("?")[0].split("#")[0]
    parts = [p for p in path.split("/") if p]
    # parts = ['https:', 'archive.org', 'details', '<book_id>', ...]
    return parts[3]


def load_script():
    spec = importlib.util.spec_from_file_location("aod", SCRIPT)
    mod = importlib.util.module_from_spec(spec)
    with contextlib.redirect_stdout(sys.stderr):
        spec.loader.exec_module(mod)
    return mod


def build_pdf_meta(metadata, book_id):
    from datetime import datetime
    meta = dict(metadata)
    for key in ["title", "creator", "associated-names"]:
        if key in meta and isinstance(meta[key], list):
            meta[key] = "; ".join(meta[key])
    pdfmeta = {}
    if "title" in meta:
        pdfmeta["title"] = meta["title"]
    if "creator" in meta and "associated-names" in meta:
        pdfmeta["author"] = meta["creator"] + "; " + meta["associated-names"]
    elif "creator" in meta:
        pdfmeta["author"] = meta["creator"]
    elif "associated-names" in meta:
        pdfmeta["author"] = meta["associated-names"]
    if "date" in meta:
        try:
            pdfmeta["creationdate"] = datetime.strptime(str(meta["date"])[0:4], "%Y")
        except Exception:
            pass
    pdfmeta["keywords"] = [f"https://archive.org/details/{book_id}"]
    return pdfmeta


def run(args):
    email = os.environ.get("ARCHIVE_EMAIL")
    password = os.environ.get("ARCHIVE_PASSWORD")
    if not email or not password:
        emit(event="error", message="Missing credentials")
        sys.exit(1)

    try:
        book_id = parse_book_id(args.url)
    except Exception:
        emit(event="error", message="Invalid book URL")
        sys.exit(1)

    aod = load_script()
    os.makedirs(args.out, exist_ok=True)

    emit(event="login")
    try:
        with contextlib.redirect_stdout(sys.stderr):
            session = aod.login(email, password)
            session = aod.loan(session, book_id)
            title, links, metadata = aod.get_book_infos(session, args.url, args.print_disabled)
    except SystemExit:
        emit(event="error", message="Login/loan failed — check credentials and that the book is borrowable.")
        sys.exit(1)
    except Exception as e:
        emit(event="error", message=f"{type(e).__name__}: {e}")
        sys.exit(1)

    if not links:
        emit(event="error", message="Book not available (it may be restricted to print-disabled patrons).")
        sys.exit(1)

    total = len(links)
    title = title or book_id
    emit(event="info", pages=total, title=title)

    scaled = [f"{link}&rotate=0&scale={args.resolution}" for link in links]
    done = 0
    with contextlib.redirect_stdout(sys.stderr):
        with futures.ThreadPoolExecutor(max_workers=50) as ex:
            tasks = [
                ex.submit(aod.download_one_image, session=session, link=link, i=i,
                          directory=args.out, book_id=book_id, pages=total)
                for i, link in enumerate(scaled)
            ]
            for _ in futures.as_completed(tasks):
                done += 1
                emit(event="page", done=done, total=total)

    emit(event="building")
    images = [aod.image_name(total, i, args.out) for i in range(total)]

    if args.format == "pdf":
        import img2pdf
        with contextlib.redirect_stdout(sys.stderr):
            pdf = img2pdf.convert(images, **build_pdf_meta(metadata, book_id))
        out_name = f"{title}.pdf"
        with open(os.path.join(args.out, out_name), "wb") as f:
            f.write(pdf)
        for img in images:
            try:
                os.remove(img)
            except OSError:
                pass
    else:
        out_name = f"{title}.zip"
        with zipfile.ZipFile(os.path.join(args.out, out_name), "w", zipfile.ZIP_DEFLATED) as z:
            for img in images:
                z.write(img, os.path.basename(img))
            if args.meta:
                z.writestr("metadata.json", json.dumps(metadata))

    with contextlib.redirect_stdout(sys.stderr):
        try:
            aod.return_loan(session, book_id)
        except (SystemExit, Exception):
            pass

    emit(event="done", id=args.job_id, filename=out_name)


def selftest():
    assert parse_book_id("https://archive.org/details/abc123") == "abc123"
    assert parse_book_id("https://archive.org/details/abc123/") == "abc123"
    assert parse_book_id("https://archive.org/details/abc123?foo=1") == "abc123"
    assert parse_book_id("https://archive.org/details/abc123/page/n1") == "abc123"
    # missing creds path emits an error and exits non-zero
    import subprocess
    r = subprocess.run(
        [sys.executable, os.path.abspath(__file__), "--url",
         "https://archive.org/details/x", "--out", "/tmp/x", "--job-id",
         "0" * 32],
        capture_output=True, text=True, env={k: v for k, v in os.environ.items()
                                             if k not in ("ARCHIVE_EMAIL", "ARCHIVE_PASSWORD")},
    )
    assert r.returncode == 1, r.returncode
    assert '"event": "error"' in r.stdout or '"event":"error"' in r.stdout, r.stdout
    print("selftest OK")


def main():
    if "--selftest" in sys.argv:
        selftest()
        return
    p = argparse.ArgumentParser()
    p.add_argument("--url", required=True)
    p.add_argument("--resolution", type=int, default=3)
    p.add_argument("--format", choices=["pdf", "jpg"], default="pdf")
    p.add_argument("--meta", action="store_true")
    p.add_argument("--print-disabled", dest="print_disabled", action="store_true")
    p.add_argument("--out", required=True)
    p.add_argument("--job-id", dest="job_id", required=True)
    run(p.parse_args())


if __name__ == "__main__":
    main()
```

```ts
// web/lib/worker.ts
export interface WorkerOpts {
  url: string;
  resolution: number;
  format: "pdf" | "jpg";
  meta: boolean;
  printDisabled: boolean;
  out: string;
  jobId: string;
}

export function buildWorkerArgs(o: WorkerOpts): string[] {
  const argv = [
    "worker.py",
    "--url", o.url,
    "--resolution", String(o.resolution),
    "--format", o.format,
    "--out", o.out,
    "--job-id", o.jobId,
  ];
  if (o.meta) argv.push("--meta");
  if (o.printDisabled) argv.push("--print-disabled");
  return argv;
}
```

```ts
// web/app/api/download/route.ts
import { spawn } from "node:child_process";
import { NextRequest } from "next/server";
import { newJobId, jobDir } from "@/lib/jobs";
import { createLineBuffer } from "@/lib/sse";
import { buildWorkerArgs } from "@/lib/worker";

export const runtime = "nodejs";

export async function POST(req: NextRequest) {
  const body = await req.json().catch(() => null);
  const url = body?.url;
  const email = body?.email;
  const password = body?.password;
  const resolution = Number(body?.resolution ?? 3);
  const format = body?.format === "jpg" ? "jpg" : "pdf";
  const meta = Boolean(body?.meta);
  const printDisabled = Boolean(body?.printDisabled);

  if (typeof url !== "string" || !url.startsWith("https://archive.org/details/"))
    return new Response("Invalid book URL", { status: 400 });
  if (!email || !password)
    return new Response("Missing credentials", { status: 400 });
  if (!Number.isInteger(resolution) || resolution < 0 || resolution > 10)
    return new Response("Resolution must be an integer 0–10", { status: 400 });

  const id = newJobId();
  const out = jobDir(id);
  const python = process.env.PYTHON_BIN || "python3";
  const argv = buildWorkerArgs({ url, resolution, format, meta, printDisabled, out, jobId: id });

  const child = spawn(python, argv, {
    cwd: process.cwd(),
    env: { ...process.env, ARCHIVE_EMAIL: email, ARCHIVE_PASSWORD: password },
  });

  const encoder = new TextEncoder();
  const buffer = createLineBuffer();

  const stream = new ReadableStream({
    start(controller) {
      let closed = false;
      const send = (line: string) => { if (!closed) controller.enqueue(encoder.encode(`data: ${line}\n\n`)); };
      const close = () => { if (!closed) { closed = true; controller.close(); } };

      child.stdout.setEncoding("utf8");
      child.stdout.on("data", (chunk: string) => { for (const l of buffer.push(chunk)) send(l); });
      child.on("close", () => { for (const l of buffer.flush()) send(l); close(); });
      child.on("error", (e) => { send(JSON.stringify({ event: "error", message: String(e) })); close(); });

      req.signal.addEventListener("abort", () => { child.kill("SIGTERM"); close(); });
    },
  });

  return new Response(stream, {
    headers: {
      "Content-Type": "text/event-stream; charset=utf-8",
      "Cache-Control": "no-cache, no-transform",
      Connection: "keep-alive",
    },
  });
}
```

```ts
// web/app/api/file/[id]/route.ts
import { createReadStream } from "node:fs";
import { readdir } from "node:fs/promises";
import { Readable } from "node:stream";
import path from "node:path";
import { jobDir, cleanup } from "@/lib/jobs";

export const runtime = "nodejs";

export async function GET(_req: Request, ctx: { params: Promise<{ id: string }> }) {
  const { id } = await ctx.params;
  let dir: string;
  try {
    dir = jobDir(id);
  } catch {
    return new Response("Not found", { status: 404 });
  }

  let files: string[];
  try {
    files = await readdir(dir);
  } catch {
    return new Response("Not found", { status: 404 });
  }

  const name = files.find((f) => f.endsWith(".pdf") || f.endsWith(".zip"));
  if (!name) return new Response("Not found", { status: 404 });

  const nodeStream = createReadStream(path.join(dir, name));
  nodeStream.on("close", () => { cleanup(id).catch(() => {}); });
  const webStream = Readable.toWeb(nodeStream) as unknown as ReadableStream;

  const type = name.endsWith(".pdf") ? "application/pdf" : "application/zip";
  return new Response(webStream, {
    headers: {
      "Content-Type": type,
      "Content-Disposition": `attachment; filename*=UTF-8''${encodeURIComponent(name)}`,
    },
  });
}
```

```tsx
"use client";
import { useState } from "react";

type Phase = "idle" | "running" | "done" | "error";

export default function Home() {
  const [phase, setPhase] = useState<Phase>("idle");
  const [status, setStatus] = useState("");
  const [error, setError] = useState("");
  const [pct, setPct] = useState<number | null>(null);

  async function onSubmit(e: React.FormEvent<HTMLFormElement>) {
    e.preventDefault();
    const f = new FormData(e.currentTarget);
    setPhase("running"); setError(""); setPct(null); setStatus("Starting…");

    const res = await fetch("/api/download", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        url: f.get("url"),
        email: f.get("email"),
        password: f.get("password"),
        resolution: Number(f.get("resolution")),
        format: f.get("format"),
        meta: f.get("meta") === "on",
        printDisabled: f.get("printDisabled") === "on",
      }),
    });

    if (!res.ok || !res.body) {
      setPhase("error");
      setError(await res.text().catch(() => "Request failed"));
      return;
    }

    const reader = res.body.getReader();
    const decoder = new TextDecoder();
    let buf = "";
    for (;;) {
      const { value, done } = await reader.read();
      if (done) break;
      buf += decoder.decode(value, { stream: true });
      const frames = buf.split("\n\n");
      buf = frames.pop() ?? "";
      for (const frame of frames) {
        const line = frame.replace(/^data: /, "").trim();
        if (!line) continue;
        handleEvent(JSON.parse(line));
      }
    }
  }

  function handleEvent(ev: any) {
    switch (ev.event) {
      case "login": setStatus("Logging in and borrowing the book…"); break;
      case "info": setStatus(`“${ev.title}” — ${ev.pages} pages`); setPct(0); break;
      case "page": setPct(Math.round((ev.done / ev.total) * 100)); setStatus(`Downloading pages ${ev.done}/${ev.total}`); break;
      case "building": setPct(100); setStatus("Building the file…"); break;
      case "done":
        setPhase("done"); setStatus(`Ready: ${ev.filename}`);
        window.location.href = `/api/file/${ev.id}`;
        break;
      case "error": setPhase("error"); setError(ev.message); break;
    }
  }

  const busy = phase === "running";
  return (
    <main>
      <h1>Archive.org Downloader</h1>
      <form onSubmit={onSubmit}>
        <label htmlFor="url">Book URL</label>
        <input id="url" name="url" placeholder="https://archive.org/details/…" required />

        <div className="row">
          <div>
            <label htmlFor="email">archive.org email</label>
            <input id="email" name="email" type="email" required />
          </div>
          <div>
            <label htmlFor="password">Password</label>
            <input id="password" name="password" type="password" required />
          </div>
        </div>

        <div className="row">
          <div>
            <label htmlFor="resolution">Resolution (0 = best … 10)</label>
            <input id="resolution" name="resolution" type="number" min={0} max={10} defaultValue={3} />
          </div>
          <div>
            <label htmlFor="format">Format</label>
            <select id="format" name="format" defaultValue="pdf">
              <option value="pdf">PDF</option>
              <option value="jpg">JPGs (ZIP)</option>
            </select>
          </div>
        </div>

        <div className="check"><input id="meta" name="meta" type="checkbox" /><label htmlFor="meta">Include metadata.json (ZIP only)</label></div>
        <div className="check"><input id="printDisabled" name="printDisabled" type="checkbox" /><label htmlFor="printDisabled">Allow print-disabled books (whitelisted accounts)</label></div>

        <button type="submit" disabled={busy}>{busy ? "Downloading…" : "Download"}</button>
      </form>

      {pct !== null && phase !== "error" && <progress value={pct} max={100} />}
      {status && <p className="status">{status}</p>}
      {error && <p className="error">{error}</p>}
    </main>
  );
}
```
